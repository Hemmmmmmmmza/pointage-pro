POINTAGE PRO

Workforce Attendance & Agricultural Productivity Management

POINTAGE PRO is a web-based application designed to simplify workforce attendance tracking and daily agricultural operations management.

Features

- Daily Attendance: Record full-day and half-day attendance.
- Workforce Management: Organize workers and teams.
- Productivity Tracking: Record and monitor daily work output.
- Recruitment & Transfers: Manage worker recruitment and transfers.
- Transportation Tracking: Organize transportation records.
- Daily Reports: Generate operational summaries and reports.
- Archives: Keep track of historical records.
- Data Export: Export reports and create data backups.

Technologies

- HTML5
- CSS3
- JavaScript
- Browser Local Storage
- html2canvas
- html2pdf.js

Getting Started

1. Clone or download this repository.
2. Open "Index.html" in a modern web browser.
3. The application runs directly in the browser.

Data Storage

The application uses browser Local Storage to store records locally on the device.

Important: Clearing browser data may delete locally stored application records. Keep regular backups.

Project Purpose

The project aims to provide a simple and practical digital solution for workforce attendance, agricultural productivity tracking, and daily operational reporting.

Maintenance
